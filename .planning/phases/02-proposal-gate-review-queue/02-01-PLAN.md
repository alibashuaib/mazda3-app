## Phase Goal

**As a** catalogue owner, **I want to** review, edit, approve, reject and revert catalogue proposals in `#admin`, **so that** nothing reaches users without my approval.

<objective>
First vertical slice: an owner opens `#admin`, sees pending proposals (written by `submit_proposal`), expands one to read the diff, confidence reasons and escaped source quotes, and approves it. Approval goes through the only live writer, `apply_proposal`, which refuses stale rows and logs every change.

Purpose: SC1 (seeded proposals visible with diff, sources, badge), SC2 (approve reaches users; stale refused), SC5 part (injection renders inert). This plan fixes the SQL signatures every later plan builds on.
Output: gate tables + 2 RPCs + 2 private helpers in schema.sql, proposals.sql CI test, Proposals tab with approve.
</objective>
