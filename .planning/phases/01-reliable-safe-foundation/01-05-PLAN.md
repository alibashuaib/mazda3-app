<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser page to app_errors (anon key, public) | Any script on the origin, or any copy of the key, can insert rows |
| error objects to stored row | Error messages may contain tokens, URLs or user text |
| service worker cache to page | Precache report is written by the SW and read by main.js |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-17 | Denial of service | error loop floods table | mitigate | session cap 30, dedupe per message, device hour cap 20, server hour cap in plan 01-01 |
| T-01-18 | Information disclosure | stack or message carries vehicle data or tokens | mitigate | allowlisted row builder; scrub() redacts sk- and JWT shapes; truncation |
| T-01-19 | Information disclosure | failed record payload logged | mitigate | logger takes only source/message/stack/route; callers never pass records (test case) |
| T-01-20 | Tampering | page forges user_id | mitigate | user_id not in insert payload; trigger overwrites it (plan 01-01) |
| T-01-21 | Denial of service | logger blocks boot | mitigate | never-reject chain; relay runs after first paint and swallows errors |
</threat_model>
