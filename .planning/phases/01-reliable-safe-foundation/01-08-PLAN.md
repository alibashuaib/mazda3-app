<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| admin-registered source URL to server fetch | Admin enters URL; server fetches it |
| remote server redirects to internal address | Attack surface through redirect and DNS |
| remote body to model input | Fetched text is later sent to the LLM |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-31 | Information disclosure | SSRF to internal addresses | mitigate | scheme, port, userinfo, host and DNS public-only checks on every hop; IPv6 expander table test |
| T-01-32 | Tampering | redirect to internal host or http | mitigate | manual redirect loop, max 3 hops, re-validation per hop; test matrix |
| T-01-33 | Denial of service | huge or endless response | mitigate | streamed byte cap, single deadline of 20 s across hops and body |
| T-01-34 | Tampering | unexpected content type passed to model | mitigate | media-type allowlist |
| T-01-35 | Information disclosure | DNS rebinding between check and connect | accept | residual: documented in SUMMARY; re-check per hop reduces window; source list is admin-registered |
| T-01-36 | Denial of service | resolver unavailable treated as public | mitigate | null or empty resolution is blocked (fail closed) |
| T-01-37 | Tampering | scraping a site that forbids it | mitigate | robots.txt honoured; 5xx or network error blocks |
</threat_model>
