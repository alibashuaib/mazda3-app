<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| arbitrary web page to edge function | Any origin can send a POST; the browser only hides the response |
| file:// or sandboxed iframe to edge function | Sends Origin null |
| pg_cron to plan-intake | Server call with no Origin, authenticated by x-cron-secret |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-07 | Elevation of privilege | read-bill used by foreign page to spend model budget | mitigate | corsDecision 403 before auth and before any model call; JWT still required |
| T-01-08 | Elevation of privilege | plan-intake triggered from foreign page | mitigate | corsDecision 403 before auth; admin JWT or cron secret still required |
| T-01-09 | Information disclosure | wildcard ACAO exposes responses to any origin | mitigate | wildcard removed; test greps both sources |
| T-01-10 | Denial of service | cron call broken by over-strict origin check | mitigate | no-Origin returns ok true (D-16); table test case covers undefined and empty string |
| T-01-11 | Spoofing | Origin header forged by non-browser client | accept | Origin is not a security boundary outside browsers; auth (JWT or cron secret) is the control |
</threat_model>
