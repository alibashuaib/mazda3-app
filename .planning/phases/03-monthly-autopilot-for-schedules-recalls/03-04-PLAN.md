<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser (admin) -> RPC | toggle, ban, approve domain |
| edge worker (service_role) -> worker RPCs | reserve, stage, publish |
| anon/other users -> tables | must see nothing |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-12 | Elevation of privilege | autopilot tables/RPCs | mitigate | RLS on all tables, admin-only select, no write policies, is_admin() inside admin RPCs, worker fns revoked from anon/authenticated |
| T-03-13 | Denial of service (cost) | autopilot_reserve | mitigate | advisory lock, cap includes open reservations, kill switch read inside same call |
| T-03-14 | Tampering | partial publish | mitigate | findings staged; publish only for clean running run; capped/killed run deletes findings |
| T-03-15 | Information disclosure | cron secret in SQL | accept | existing plan-intake pattern; Vault noted as upgrade, no secret committed |
| T-03-16 | Tampering | unseen/banned domains | mitigate | source_domains status checked by autopilot_see_domain; ban auto-rejects pending proposals |
| T-03-SC | Tampering | npm installs | accept | none installed |
