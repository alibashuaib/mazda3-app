# External Integrations

**Analysis Date:** 2026-11-04

## APIs & External Services

**LLM (Anthropic):**
- Anthropic Messages API (`https://api.anthropic.com/v1/messages`, `anthropic-version: 2023-06-01`) via raw `fetch`, no SDK
  - `supabase/functions/read-bill/index.ts` - vision read of bill photos; default model `claude-haiku-5-5` (`BILL_MODEL`)
  - `supabase/functions/plan-intake/index.ts` - drafts maintenance schedule from admin-registered source URLs; default model `claude-sonnet-5-5` (`INTAKE_MODEL`)
  - Auth: `ANTHROPIC_API_KEY` (function secret)

**Vehicle recalls:**
- NHTSA recalls API (`https://api.nhtsa.gov/recalls/recallsByVehicle`) - called from `supabase/functions/plan-intake/index.ts`; results stored as `pending` rows in `recalls`, shown via `src/data/recalls.js`. No auth.

**Parts links:**
- `https://partsouq.com` - outbound link only (see `src/`), no API.

## Data Storage

**Databases:**
- Supabase Postgres (project URL in `src/data/account.js`)
  - Schema: `supabase/schema.sql` (vehicles, garage, price_items, price_observations, contributions, shops, shop_feedback, insights_prefs, bill_reads, profiles, car_models, dealer_plan_items, dealer_plan_changes, schedule_sources, recalls, plan_drafts); extensions `pg_trgm`, pg_cron
  - Seed: `supabase/seed-catalogue.sql` generated by `tools/seed-catalogue.js`
  - RLS/SQL tests: `supabase/tests/*.sql`
  - Client: vendored `@supabase/supabase-js` (`.from()`, `.rpc()`, `.functions.invoke()`)

**File Storage:**
- Supabase Storage bucket `photos` (per-user car photos; policy in `supabase/schema.sql`)
- Local: IndexedDB (http) or localStorage (`file://`) via `src/data/storage.js`

**Caching:**
- Service worker Cache API (`sw.js`)

## Authentication & Identity

**Auth Provider:**
- Supabase Auth, email + password (`signUp` / `signInWithPassword`) in `src/data/account.js`; session state in `src/data/session.js`
- Admin role via `profiles` table; admin UI `src/pages/admin.js`, `src/data/admin.js`
- Edge functions validate user JWT with anon key; service role key used server-side only

## Monitoring & Observability

**Error Tracking:**
- None

**Logs:**
- Console only; `bill_reads` table holds usage/dedup metadata (hash, store_key, city; no bill text)

## CI/CD & Deployment

**Hosting:**
- Not detected in repo (static files; any static host). Edge functions deployed with `supabase functions deploy`.

**CI Pipeline:**
- GitHub Actions `.github/workflows/test.yml`: `tests` job (npm ci, npm test, `node --check` all JS) and `browser` job (Playwright chromium)

## Environment Configuration

**Required env vars (Edge Functions):**
- `ANTHROPIC_API_KEY`, `INTAKE_CRON_SECRET` (plan-intake), `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY` (auto-provided)
- Optional: `BILL_MODEL`, `INTAKE_MODEL`, `BILL_GLOBAL_DAILY_CAP`

**Secrets location:**
- Supabase function secrets. Client ships only the public anon key (committed in `src/data/account.js`; access controlled by RLS).

## Webhooks & Callbacks

**Incoming:**
- `plan-intake` function invoked by pg_cron (job `plan-intake`) authenticated with `INTAKE_CRON_SECRET`

**Outgoing:**
- None
